# Design Critique Rubric

Run this lightweight rubric after bundle self-audit and before finalizing output.

## Goal
Catch outputs that are structurally correct but still feel generic, flat, overly safe, or visually undercooked.

## Score each dimension from 1-10

### 1. Philosophy alignment
- Does the screen actually express the chosen style direction?
- Are there contradictory visual cues that dilute the direction?

### 2. Visual hierarchy
- Is there a clear entry point?
- Do the major zones feel meaningfully different in emphasis?
- Can the user find the primary action in one glance?

### 3. Craft and detail execution
- Are spacing, alignment, and repeated patterns disciplined?
- Is there at least one detail that feels intentionally refined rather than template-default?

### 4. Functionality and credibility
- Does the screen still look like a believable working product, not a poster?
- Do forms, results, tables, and toolbars read as operational surfaces?

### 5. Originality without gimmick
- Is there at least one memorable design move?
- Is that move subordinate to product clarity rather than competing with it?

## Repair triggers
If any dimension scores below 7, repair before final output.

## Common repairs
- Strengthen hierarchy before adding decoration
- Remove repetitive equal-weight cards
- Replace generic helper copy with more product-specific language
- Add one refined signature detail instead of many small effects
- Reduce decorative noise that weakens task clarity
